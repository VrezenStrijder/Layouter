# 更新日志
## 未发布 (Unreleased)
- 修复托盘菜单「检测新版本」导致程序崩溃的问题
- 修复备份列表中备份状态显示为「无效」的问题
- 修复插件详情等窗口垂直滚动条滑块显示为横线的问题
- 表格选中行改为强调色底 + 白色文字，并修复单元格内容未垂直居中的问题
- 新增主题化消息对话框(AppMessageBox)，替换全部 116 处系统 MessageBox
- 新增主题化通知卡片(AppToastService)，用于备份完成、分区锁定等非阻塞提示
- 分区管理窗口新增「刷新」按钮，新建分区后列表自动更新
- 重做备份与还原窗口布局：左侧创建表单与详情、右侧备份列表
- 隐藏目录不再残留于桌面：被隐藏的桌面图标改存于应用数据目录，存放名称使用哈希摘要，原始路径映射写入 NTFS 备用数据流(ADS)，开启"显示隐藏文件"也无法在桌面看到
- 自动迁移旧版桌面隐藏目录(.layouterhidden)到新的安全隐藏存储
- 新增配置备份与还原功能：可自定义备份根目录，备份支持名称与备注，程序内可查看备份列表、还原、删除
- 统一界面风格：新增设计令牌(Theme.xaml)与统一控件样式(AppControls.xaml)，重做分区管理、分区设置、软件更新、插件管理与托盘菜单界面
- 分区管理窗口新增"新建分区"入口与空状态提示
