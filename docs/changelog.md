# 更新日志
## 2.1.0 (2026-10-31)
- 新增备份和还原功能，支持自定义备份目录、备份名称与备注，程序内可查看备份列表、还原、删除
- 新增预设主题功能，支持使用预设主题快速切换分区卡片风格
- 使用ADS(Alternate Data Streams)存储隐藏桌面图标的原始路径，开启"显示隐藏文件"也无法在桌面看到
- 新增双击桌面切换桌面图标显示效果功能
- 更新界面UI并统一界面风格

## 2.0.0 (2026-06-03)
- 增加插件模块，包含内置的插件编辑器，支持用户自定义插件
- 优化卡片窗口的拖动功能，可自动按图标行列数目布局
- 优化UI界面

## 1.0.4 (2025-05-08)
- 新增软件更新的功能，可以在软件中直接升级新版本了
- 将图表右键菜单替换为系统的右键菜单，支持更多功能

## 1.0.3 (2025-05-03)
- 修复自动排列图标的问题，支持改变窗口大小时自动重新排列
- 支持一次拖动多个桌面图标到分区
- 取消拖动时窗口半透明效果，便于实时观察窗口动态

## 1.0.2 (2025-04-30)
- 美化分区窗口样式
- 新增双击标题栏空白处隐藏/显示图表区域的功能

## 1.0.1 (2025-04-22)
- 新增对普通目录的拖动支持
- 修复拖动系统桌面图标后无法隐藏的问题
- 修复UserProfile目录判定的问题

## 1.0.0 (2025-04-19)
- 初始版本发布
